# Enterprise Infrastructure Lab

A hands-on project that documents my journey in building and managing an enterprise-like IT infrastructure using Windows Server technologies.

This repository is focused on practical learning through lab environments that simulate real-world enterprise scenarios. Each lab is documented with deployment steps, configuration, challenges encountered, solutions, and key lessons learned.

## Project Goals

* Build a complete enterprise Windows Server environment.
* Gain practical experience with enterprise infrastructure technologies.
* Improve system administration and networking skills.
* Document hands-on labs for future reference and continuous learning.

## Technologies

* Windows Server
* Active Directory Domain Services (AD DS)
* DNS
* DHCP
* Group Policy (GPO)
* WSUS
* File Server
* DFS
* WDS
* PowerShell
